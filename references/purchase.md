# 购房全流程与税费计算（通用版）

---

## Phase 1：需求确认

- [ ] 确定购房目的（自住/投资/改善/学区）
- [ ] 确定城市（限购政策先查清楚）
- [ ] 设定预算（首付能力 + 月供承受能力）
- [ ] 明确区域偏好（工作通勤、生活配套）
- [ ] 确定户型和面积要求
- [ ] 确定新房/二手房偏好
- [ ] 计算购房资格（社保/个税年限、贷款记录）

---

## Phase 2：政策与费用摸底

### 限购政策查询
- [ ] 查询目标城市的限购政策（社保/个税年限）
- [ ] 查询是否有首套房认定（认房又认贷/认房不认贷）
- [ ] 查询限购套数限制

### 贷款政策查询

| 关键指标 | 说明 |
|---------|------|
| 首付比例 | 首套/二套，各地不同 |
| 贷款利率 | LPR+基点，当前行情 |
| 贷款年限 | 最长30年（商贷）/25年（公积金） |
| 公积金 | 缴存基数、贷款额度 |

### 税费计算（必须提前算清）

**新房税费**：

| 税费 | 计算方式 | 备注 |
|------|---------|------|
| 契税 | 房价 × 税率（1%-3%） | 首套90㎡以下1%，以上1.5% |
| 维修基金 | 房价 × 2-3% | 各地不同 |
| 印花税 | 房价 × 0.05% | 目前免征或极低 |

**二手房税费**：

| 税费 | 计算方式 | 备注 |
|------|---------|------|
| 契税 | 同新房 | |
| 增值税 | 差价 × 5.3% | 满2年免征 |
| 个人所得税 | 房价 × 1-2% | 满5唯一免征 |
| 中介费 | 房价 × 1-3% | 可谈 |

### 总费用估算公式

```
实际购房总成本 = 房价 + 税费 + 中介费 + 过户费 + 装修费
首付 ≈ 房价 × 首付比例 + 税费 + 中介费
```

## Phase 3：渠道收集

### 新房渠道
- [ ] 品牌开发商（万科、保利、龙湖等）更有保障
- [ ] 查"五证"是否齐全：土地证/规划证/施工证/预售证/销售证
- [ ] 关注工地进度和开发商资金链新闻

### 二手房渠道
- [ ] 贝壳/链家：房源真实度高，有VR看房
- [ ] 找1-2个靠谱经纪人（朋友推荐）
- [ ] 问清中介费通常1-2%可谈

### 法拍房（高风险）
- ⚠️ 价格低但风险高，需全款，可能有长租约/落户占用
- ⚠️ 建议新手绕道

---

## Phase 4：看房与筛选

**红线警告（新房）**：
- ⚠️ 五证不齐全
- ⚠️ 价格明显低于周边（资金链可能有问题）
- ⚠️ 工地停工/进度异常
- ⚠️ 开发商有烂尾前科

**二手房必查**：
- [ ] 房产证（产权人、地址、面积、性质）
- [ ] 户籍情况（是否有人落户）
- [ ] 租赁情况（有无长租约，影响过户）
- [ ] 抵押查封（是否有债务纠纷）

---

## Phase 5：房屋核验（必须做！）

### 线上查询
- [ ] 不动产登记查询（各地政务APP）
- [ ] 企查查/天眼查（查房东是否有纠纷）
- [ ] 中国执行信息公开网（查是否为老赖）

### 线下核验
- [ ] 拉取不动产登记簿（在市民中心/不动产中心）
- [ ] 确认产权人、抵押情况、查封情况

---

## Phase 6：谈判与签约

### 谈判要点
- [ ] 了解业主卖房动机（急售可压价）
- [ ] 对比同小区近期成交价
- [ ] 明确税费谁来承担
- [ ] 谈中介费（通常1-2%，可谈）
- [ ] 留好谈价空间，别暴露底价

### 合同关键条款
- [ ] 成交价格和付款方式（定金/首付/尾款）
- [ ] 付款时间节点
- [ ] 过户时间
- [ ] 房屋交付标准（空置/带租约/带家具）
- [ ] 违约责任（定金双倍/违约金比例）
- [ ] 户口迁出时间（如有）
- [ ] 漏水/凶宅等特殊情况约定

---

## Phase 7：贷款与过户

### 贷款流程
```
资质预审 → 银行面签 → 审批通过 → 过户 → 抵押登记 → 放款
```

### 面签前准备
- [ ] 收入证明、银行流水
- [ ] 征信报告（提前查）
- [ ] 身份证、户口本、婚姻状况证明

---

## Phase 8：收房与装修

### 收房检查
| 类别 | 检查项 |

## 购房 vs 租房 选择指南

| 维度 | 购房 | 租房 |
|------|------|------|
| 适用场景 | 长期定居(5年+)、改善需求、学区需求 | 短期过渡、工作不稳定、投资过渡 |
| 资金门槛 | 高（首付+税费+装修） | 低（押金+租金） |
| 月供 vs 租金 | 相当或略高，但资产沉淀 | 低，但无资产积累 |
| 灵活性 | 低（换房成本高） | 高 |

### 租购比决策公式

```
租购比 = 购房总价 / 年租金
<20  → 买房比租房划算
20-30 → 基本平衡
30-40 → 租房更划算
>40  → 租房明显优于，慎重
```

## 常见问题速查

**Q: 怎么判断开发商会不会烂尾？**
1. 查"三道红线"踩线情况（恒大/碧桂园等）
2. 查工地进度（实地踩盘、业主群）
3. 选国企/央企更稳妥

**Q: 二手房定金能退吗？**
- **不能**。定金是购房意向，一旦房东收定，买家反悔则定金不退
- **例外**：合同有约定退还条款，或房东违约（双倍返还）

**Q: 学区房一定能上学吗？**
- **不一定**。学区划分每年可能调整，关注落户年限、学位占用

**Q: 房龄超过多少年不建议买？**
- 一般超过20年流通性较差，超过30年贷款难、配套差
- 老破小看地段（核心地段仍有价值）
