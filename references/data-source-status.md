## 链家小区详情页搜索方法（推荐）

通过搜索引擎可以获取链家小区参考均价和成交数据：

**搜索词格式**：
```bash
# 格式：`小区名 链家 均价 二手房 2025`
# 示例：`马家堡西里 链家 均价 二手房 2025` → 返回：均价¥43,258/㎡，在售53套
# 示例：`角门东里 链家 均价 二手房 2025` → 返回：均价¥42,713/㎡，在售57套

# 精确查找小区详情页
site:lianjia.com/xiaoqu/ 小区名
```

**这种方式比安居客更可靠**（安居客过期房源多）

## 数据准确性警告

**购房数据必须用权威来源验证，禁止直接呈现未经核实的搜索结果。**

- ❌ 错误：搜索返回什么列什么，不核实来源和板块归属
- ❌ 错误：跨区域混合搜索，合并时不做交叉验证
- ✅ 正确：分小区逐个查，合并时再次验证板块归属
- ✅ 正确：呈现数据时标注来源（链家/安居客/贝壳研究院等）

## 安居客过期房源问题（根因分析）

**现象**：Tavily搜索返回的安居客房源大量已下架

**原因**：Tavily抓取的是历史索引，不是实时挂牌数据。

**缓解方案**：
1. 搜索安居客时用 `site:anjuke.com/fangyuan/` 限定详情页
2. **购房场景首选链家xiaoqu/搜索**，不安居客作为主要来源
3. 让用户截图验证（100%实时，但无法生成自动比对表）

## 第三方API调研

### 云房数据（yunfangdata.com）
- **类型**：参考价/估值，非实时挂牌
- **接口**：`/dataapi/api_001.html`（房屋询价）
- **返回**：`{rent, price, totalprice}`
- **适合**：估算"这个小区大概能租/售多少钱"
- **不适合**：实时查找在租房源

### 乐有家（leyoujia.com）
- **类型**：真实挂牌数据
- **城市**：深圳、中山、东莞、惠州、广州、佛山、清远、珠海、江门、长沙、南京
- **北京/上海 ❌ 不支持**
- **申请**：联系乐有家申请 `X-Api-Key`

### 小鹿选房
- **类型**：真实挂牌数据
- **城市**：需实测
- **申请**：`https://www.xiaoluxuanfang.com/claw`

## 结论

中国房产实时房源数据的核心矛盾：**能提供实时数据的平台（贝壳/链家/自如）API封闭；开放API的平台（安居客/58）数据不实时。**

**购房场景数据优先级**：
1. 链家/贝壳小区详情页（xiaoqu/）→ 通过搜索获取，精确可靠 ✅
2. 贝壳研究院/克而瑞报告 → 有1-3个月滞后但权威
3. 安居客小区详情页 → 有过期房源问题，需交叉验证

**租房场景数据优先级**：
1. 用户截图验证（100%实时）
2. 安居客/58搜索（注意过期率）
3. 小红书真实体验（辅助验证）
