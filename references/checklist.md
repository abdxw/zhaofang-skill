# 看房/签约检查清单

## 看房前准备

- [ ] 确认预算（首付+月供承受能力）
- [ ] 查好小区参考均价（用链家xiaoqu/搜索）
- [ ] 确认通勤路线和时间（用高德API实测）
- [ ] 准备好问题清单（户型/装修/邻居/物业等）

---

## 租房看房 Checklist

### 房屋本身
| 检查项 | 说明 |
|--------|------|
| 户型图与实际是否一致 | 有无隔断/违建 |
| 采光通风 | 各房间窗户是否正对天井/楼道 |
| 装修状况 | 地板/墙面/厨卫是否需要大修 |
| 设施设备 | 水电燃气/空调/热水器是否正常 |
| 隔音 | 隔壁/楼上噪音是否明显 |
| 漏水 | 墙角/天花板是否有水渍 |

### 小区/楼层
| 检查项 | 说明 |
|--------|------|
| 电梯 | 是否正常，楼道是否干净 |
| 门禁 | 单元门/入户门是否安全 |
| 物业 | 公共区域卫生、停车管理 |
| 邻居 | 有无群租/噪音/特殊行业 |
| 周边 | 便利店/菜市场/饭馆距离 |

### 签约前
| 检查项 | 说明 |
|--------|------|
| 房东身份 | 房产证+身份证核对 |
| 房产证 | 产权人/地址/面积/性质 |
| 租赁合同 | 关键条款（租金/押金/租期/违约） |
| 押金条款 | 退房时退还条件 |
| 费用结算 | 上家水电燃气是否结清 |
| 户籍情况 | 有无落户需求，房东是否配合 |

## 购房看房 Checklist

### 新房看盘
| 维度 | 检查项 |
|------|--------|
| 区位 | 规划图、地铁/公交、自驾到市中心时间 |
| 配套 | 已建成/规划中的学校/商业/医院 |
| 小区 | 规划户数、车位比、容积率、绿化率 |
| 楼栋 | 楼间距、采光分析、噪音源 |
| 户型 | 方正、南北通、得房率 |
| 价格 | 备案价、实际成交价、周边竞品对比 |
| 开发商 | 口碑、在建项目、资金状况 |

**红线警告（新房）**：
- ⚠️ 五证不齐全
- ⚠️ 价格明显低于周边（资金链可能有问题）
- ⚠️ 工地停工/进度异常
- ⚠️ 开发商有烂尾前科

### 二手房看房
| 类别 | 检查项 |
|------|--------|
| 房屋结构 | 户型图与实际是否一致、有无违建 |
| 采光通风 | 各房间采光、窗户密封 |
| 装修状况 | 地板/墙面/厨卫、是否需要大修 |
| 设施设备 | 水电燃气是否正常、空调/热水器 |
| 楼层 | 电梯是否正常、逃生通道 |
| 邻居 | 群租/噪音/特殊行业（影响落户/贷款） |
| 物业 | 门禁、卫生、停车 |

**二手房必查**：
- [ ] 房产证（产权人、地址、面积、性质）
- [ ] 户籍情况（是否有人落户）
- [ ] 租赁情况（有无长租约，影响过户）
- [ ] 抵押查封（是否有债务纠纷）
- [ ] 土地性质（商品房/经适房/房改房）

## 签约注意事项

### 谈判要点
- [ ] 了解业主卖房动机（急售可压价）
- [ ] 对比同小区近期成交价
- [ ] 明确税费谁来承担
- [ ] 谈中介费（通常1-2%，可谈）
- [ ] 留好谈价空间，别暴露底价

### 合同关键条款
- [ ] 成交价格和付款方式（定金/首付/尾款）
- [ ] 付款时间节点
- [ ] 过户时间
- [ ] 房屋交付标准（空置/带租约/带家具）
- [ ] 违约责任（定金双倍/违约金比例）
- [ ] 户口迁出时间（如有）
- [ ] 漏水/凶宅等特殊情况约定

### 购房额外注意
- [ ] 不动产登记簿（查抵押/查封）
- [ ] 企查查/天眼查（查房东是否有纠纷）
- [ ] 中国执行信息公开网（查是否为老赖）
- [ ] 合同条款：学区承诺/落户配合/凶宅条款
