# zhaofang - AI 找房助手

> 一个适用于 AI Agent（Hermes Agent / OpenClaw）的通用找房技能，支持租房和购房场景，数据源优先级明确，通勤计算有据可查。

---

## 功能

- **房源信息整合**：多平台数据搜索（链家/安居客/58等）
- **通勤时间计算**：高德 API v3 真实路线规划（非直线距离）
- **板块分析报告**：判断某个板块是否值得入手
- **看房/签约检查清单**：避坑要点覆盖
- **多维评分体系**：辅助决策

---

## 适用场景

| 场景 | 说明 |
|------|------|
| 租房 | 用户说"帮我找XX附近一居室，预算XXX"，AI 自动搜索+比对 |
| 购房 | 小区均价查询、板块分析、税费计算、购房流程指导 |
| 通勤评估 | 计算两个地点之间的真实通勤时间（驾车/公交） |
| 避坑 | 看房检查清单、签约注意事项 |

---

## 数据源优先级

> 这是本 skill 的核心方法论：**购房数据必须用权威来源验证，禁止直接呈现未经核实的搜索结果。**

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 链家/贝壳小区详情页（xiaoqu/） | 搜索 `小区名 链家 均价 二手房 2025`，精确可靠 |
| 2 | 贝壳研究院/克而瑞报告 | 有滞后但权威 |
| 3 | 安居客小区详情页 | 交叉验证用，注意过期房源 |

详见：[references/data-source-status.md](references/data-source-status.md)

## 环境配置

### 必须

```bash
export TAVILY_API_KEY="你的Tavily搜索API密钥"
```

### 推荐

```bash
export AMAP_KEY="你的高德Web服务Key"  # 用于通勤时间计算
```

获取方式：
- **Tavily**：[https://tavily.com](https://tavily.com) 注册后获取
- **高德 Web 服务 Key**：[https://console.amap.com/dev/key/app](https://console.amap.com/dev/key/app) → 添加Key → 应用类型选「Web服务」

> ⚠️ 高德移动端Key不能用于HTTP请求，必须申请Web服务Key。

## 已知限制

1. **实时房源数据没有免费方案**：贝壳/链家/自如API封闭，安居客/58数据不实时
2. **安居客过期房源**：搜索返回历史索引，建议用户截图验证（100%实时）
3. **高德 Key 类型**：必须为Web服务类型，移动端Key无法用于HTTP接口

---

## 关键设计原则

1. **数据准确性优先于搜索速度**：禁止跨区域混合搜索，分小区逐个查，合并时交叉验证
2. **通勤数据必须用 API 实测**：不能用 haversine 直线距离代替
3. **呈现数据必须标注来源**：链家/安居客/贝壳研究院等，让用户知道数据可信度
